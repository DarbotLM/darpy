# Source provenance

The legacy robot coverage planner in the repository root derives from
[oldworship/DARP-python](https://github.com/oldworship/DARP-python) and
[alice-st/DARP](https://github.com/alice-st/DARP). Existing source history and
attribution are retained. The inspected baseline is
`3dc06ee15c117c95eb642eb289b1c142fe078ac7`.

The platform modules under `src/darpy`, new tests, and platform documentation
were developed for DarbotLabs. No blanket license grant for inherited source
is inferred by this change. A distribution license decision and confirmation
of inherited-source terms remain release requirements before public package
publication. Development wheel builds do not constitute a published release.

The companion [Darbot Python SDK](https://github.com/DarbotLM/darpy-sdk)
derives from the Model Context Protocol Python SDK and retains that project's
MIT copyright and license notices. Protocol names and identifiers remain
those of their respective specifications.
